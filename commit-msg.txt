fix(ui): 右键打开机器界面 + 方块改成静态模型渲染

两个都是「用户实测发现的」问题：

1. 打不开 UI（完全打不开，右键没反应）
   - MachineBlock#use 原来直接返回 PASS（TODO 状态），现在转发给 MetaMachine#tryToOpenUI；
   - MetaMachine 实现 LDLib 的 IUIHolder，新增 shouldOpenUI / tryToOpenUI / createUI；
   - 新增 api.gui.factory.MachineUIFactory（LDLib UIFactory 实现，holder 压成方块坐标同步），
     由 Ogmr 构造期 UIFactory.register(MachineUIFactory.INSTANCE) 注册 —— LDLib 的
     UIFactory 构造器不会自动注册自己；
   - UI 自动注册：builder 没给界面时自动给一个 MachineUI.createDefault(...) 的零配置界面
     （标题 + 玩家背包 + 右侧信息栏 + 按机器实际暴露的物品/流体仓储自动摆的槽位），
     新增链式 .ui(MachineUI)；只写了 .editableUI(ui.buildEditable()) 的 addon 也能被认出来
     （EditableMachineUI 记 owner）。

2. 方块贴图为空、物品栏正常
   - MachineBlock#getRenderShape 原来无条件返回 ENTITYBLOCK_ANIMATED（GTM 写法），
     意思是「静态模型别画、交给 BER」，而本库默认不注册 BER → 世界里什么都不画；
   - 现在默认 MODEL（走数据生成的 blockstates/models），只有定义里显式 .entityRenderer(true)
     才用 ENTITYBLOCK_ANIMATED。

顺带修掉一个 API 缺陷：MachineUI 的动态文本/进度取值器原来是无参 Supplier，
而一份 MachineUI 是所有同类机器共用的模板 —— 装配时才知道是哪一台，所以改成
Function<MetaMachine, ...>（保留常量式 Supplier 重载）。MachineUIWidget 增加
getFullWidth/getFullHeight 让右侧信息栏不被 ModularUI 裁掉。

test 包：test_multiblock 给了一个显式界面（进度条 + 线程数文本）做示范；datagen 阶段
会打出每台机器的 UI 情况（UI of ogmr:xxx = 176x166, entries=.., autoLayout=..）。
README 增补 §11 机器界面、§12 自定义配方内容种类，并补上渲染方式的坑。
